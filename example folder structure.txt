ROM examples
============

Standard console game:
assets/roms/snes/Super Mario World (USA).sfc
assets/roms/snes/boxart/Super Mario World.png

DOS game (keep the executable inside its game folder):
assets/roms/dos/blood/BLOOD.EXE
assets/roms/dos/boxart/blood.png

HTML5 game (the folder must contain index.html):
assets/roms/html5/Eaglercraft/index.html
assets/roms/html5/boxart/Eaglercraft.png

Mixed-format favorite:
assets/roms/secret/Super Mario World.sfc
assets/roms/secret/boxart/Super Mario World.png

Run run_scraper.bat after adding or removing games. The generated library.json
is the file loaded by the website; artwork is matched by the scraper and does
not need to be listed manually in index.html.
